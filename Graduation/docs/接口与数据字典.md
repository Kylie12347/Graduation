# 接口与数据字典

## 请求约定

基础地址：`http://127.0.0.1:8080/api`。JSON请求使用`Content-Type: application/json`。除登录外，携带`Authorization: Bearer <token>`。

成功直接返回对象或数组。错误返回`{"message":"中文原因"}`：400参数错误，401未登录/过期，403越权，409业务状态或数量冲突。金额为整数分，重量为整数克，时间为毫秒级Unix时间戳。

## 消费者接口

| 方法 | 路径 | 请求/作用 |
|---|---|---|
| POST | /auth/login | `{role:"CONSUMER"}`或`{role:"ADMIN",password:"..."}` |
| GET | /cabinets | 柜体列表与占用/柜门状态 |
| GET | /products | 商品标称资料 |
| POST | /sessions | `{cabinetId:"CAB001"}`申请开柜 |
| GET | /sessions | 当前消费者的会话 |
| GET | /sessions/{id} | 会话、观测、融合结果、净清单和订单 |
| POST | /sessions/{id}/close | 关柜并创建REVIEW订单 |
| POST | /sessions/{id}/events/{event}/resolve | `{productId,quantity,direction,note}`，direction为TAKE/RETURN |
| GET | /orders | 当前身份订单列表 |
| GET | /orders/{id} | 订单快照及支付尝试 |
| POST | /orders/{id}/confirm | 检查异常全部完成、锁定金额 |
| POST | /orders/{id}/pay | `{requestKey:"唯一请求键",success:true}`模拟支付 |
| POST | /orders/{id}/cancel | 仅无实际柜外商品时可直接取消 |

## 管理员接口

| 方法 | 路径 | 请求/作用 |
|---|---|---|
| GET | /admin/dashboard?date=2026-10-27 | 指定上海时区营业日，省略日期为当天 |
| GET | /admin/stocks | 柜内库存、待结算、已售、预警及差异 |
| GET | /admin/sessions | 最近200次会话 |
| GET | /admin/orders | 最近200笔订单 |
| GET | /admin/inventory-logs | 最近200条库存流水 |
| POST | /admin/products | `{id,name,priceCents,weightGrams,thresholdQty,enabled}`新增/更新 |
| POST | /admin/cabinets | `{id,name,location}`创建虚拟柜体 |
| POST | /admin/restock | `{cabinetId,productId,quantity}`补货1—1000件 |
| POST | /admin/sessions/{id}/simulate | 人为生成取放及多源数据，见下例 |
| POST | /admin/sessions/{id}/return-and-cancel | 全部实际归还并取消 |

```json
{
  "productId": "COLA",
  "direction": "TAKE",
  "quantity": 1,
  "weightError": 5,
  "rfidMiss": false,
  "rfidOverride": "",
  "visionDifferent": false
}
```

重量误差允许−500至500克，数量1—10。RFID漏读优先于rfidOverride；未漏读且覆盖SKU为空时正常输出，填其他SKU时模拟错误识别。视觉只输出有无差异。

## 核心数据库表

| 表 | 主要字段 | 目的 |
|---|---|---|
| products | id,name,price_cents,weight_grams,threshold_qty,enabled | SKU资料及补货阈值 |
| cabinets | id,name,location,door_open,active_session | 柜门与占用状态 |
| stocks | cabinet_id,product_id,on_hand,supplied,sold | 物理库存和销售记账 |
| shopping_sessions | id,user_id,cabinet_id,state,created_at,closed_at,order_id | 一次开柜购物 |
| simulation_actions | id,session_id,product_id,direction,quantity | 仿真操作真值 |
| perception_events | signal_json,result_json,status,resolved_* | 观测、原始算法结果、独立人工确认 |
| orders | session_id,user_id,state,total_cents,items_json,paid_at | 唯一会话订单与价格快照 |
| payments | order_id,request_key,state,amount_cents,created_at | 支付尝试与唯一幂等键 |
| inventory_logs | cabinet_id,product_id,kind,quantity,reference_id | 初始、取出、放回、补货及支付销售留痕 |

当前小规模单机教学系统采用主键、唯一约束及Service校验保证一致性；若扩充大量柜体，应补充分页、外键约束和按会话/支付时间建立的索引。
